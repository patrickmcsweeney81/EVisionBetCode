# New Computer Setup Guide

**Quick Transfer for EVisionBet to New Machine**

---

## ⚡ Fast Track (15 minutes)

### Prerequisites
- Git installed (https://git-scm.com/download/win)
- Python 3.10+ installed (https://www.python.org/downloads/)
- VS Code installed (https://code.visualstudio.com/)
- Node.js 16+ installed (https://nodejs.org/)

### Step 1: Clone Repositories
```powershell
# Create workspace folder
mkdir C:\EVisionWorkspace
cd C:\EVisionWorkspace

# Clone both repos
git clone https://github.com/patrickmcsweeney81/EVisionBetCode.git
git clone https://github.com/patrickmcsweeney81/EVisionBetSite.git

# Navigate to backend
cd EVisionBetCode
```

### Step 2: Setup Backend (2 minutes)
```powershell
# Create and activate Python venv
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Install dependencies
pip install -e ".[dev]"

# Create .env file with API key
# Get key from: https://the-odds-api.com/
echo ODDS_API_KEY=your_key_here > .env
```

### Step 3: Setup Frontend (3 minutes)
```powershell
# In new terminal, navigate to frontend
cd C:\EVisionWorkspace\EVisionBetSite\frontend

# Install dependencies
npm install
```

### Step 4: Start Everything (3 minutes)
```powershell
# Terminal 1: Backend
cd C:\EVisionWorkspace\EVisionBetCode
.\.venv\Scripts\Activate.ps1
uvicorn backend_api:app --reload

# Terminal 2: Pipeline (extract fresh data)
cd C:\EVisionWorkspace\EVisionBetCode
.\.venv\Scripts\Activate.ps1
python run_nba_pipeline.py --extract

# Terminal 3: Frontend
cd C:\EVisionWorkspace\EVisionBetSite\frontend
npm start
```

### Step 5: Verify
- Frontend: http://localhost:3000 (should show EV opportunities)
- API Health: http://localhost:8000/health
- API Docs: http://localhost:8000/docs

## 🆘 Troubleshooting

### Python venv not activating
```powershell
# Use absolute path
C:\EVisionWorkspace\EVisionBetCode\.venv\Scripts\Activate.ps1
```

### "pip install -e" fails
```powershell
# Upgrade pip first
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

### npm packages missing
```powershell
# Clear and reinstall
rm -r node_modules package-lock.json
npm install
```

### API credit issues
- Check https://the-odds-api.com/your-account
- Verify .env has correct ODDS_API_KEY
- Pipeline uses ~864 credits per full run

### Port 3000 or 8000 in use
```powershell
# Find process
netstat -ano | findstr :3000
# Kill process
taskkill /PID <pid> /F
```
